# Lab 02: env

Move database credentials into environment configuration.

## Starting point

Run `make prepare LAB=02 RUNTIME=podman` (or Docker). Use the same INSTANCE and PORT_BASE in every command. Preparation leaves lab 01 completed and this exercise unsolved.

Read [the command and custody guide](../docs/automation/usage.md). Learner code is `.build/<INSTANCE>/backend/connector.js`; runtime environment is `.secrets/<INSTANCE>/backend.env`. Keep credentials private. An initialized instance has recovery credentials in its private init.json; manual administrative work is explicit, while automation uses scoped identities.

## Exercise

Replace the hardcoded credential construction in the learner connector with reads from POSTGRES_DB_HOST, POSTGRES_DB_PORT, POSTGRES_DB, POSTGRES_USER and POSTGRES_PASSWORD. The prepared backend.env already supplies the workshop values. Preserve the getCredentials export and return source `env-file`. Restart the backend and confirm DB access.

After editing connector code, restart the instance backend using Compose. After editing backend.env, recreate it so the environment is reloaded. With default instance and Podman:

```sh
podman compose --env-file config/defaults.env --env-file .env -f .secrets/workshop/compose.yml -p zt-workshop up -d --no-deps --force-recreate backend
make verify LAB=02 RUNTIME=podman
```

Use `docker-compose` in place of `podman compose` for standalone Docker Compose. Adapt paths/project when using another INSTANCE. The verifier checks behavior; it never applies the solution. Probes may create temporary login/lease records and, for CIBA, one uniquely named test order that is deleted afterward.

## Hints

Inspect `data/connector.env.js`, the manifest's required features and existing subsystem docs. Use API/SQL observations to diagnose failures rather than changing completion markers. Preserve getCredentials and the optional lifecycle exports consumed by the existing pool manager.

## Reference solution

To intentionally replace your work, use `make resolve LAB=02 RUNTIME=podman OVERWRITE=1`. Edited connector files are backed up privately. Inspect `ansible/tasks/`, `ansible/library/`, `terraform/workshop/` and the local connector example to understand each change. Manually created mounts/policies require explicit `make adopt LAB=02` before later automated resolution; verification itself never requires adoption.
