# Lab 07: agent-dynamic

Consume credentials rendered by Vault Agent.

## Starting point

Run `make prepare LAB=07 RUNTIME=podman` (or Docker). Use the same INSTANCE and PORT_BASE in every command. Preparation leaves lab 06 completed and this exercise unsolved.

Read [the command and custody guide](../docs/automation/usage.md). Learner code is `.build/<INSTANCE>/backend/connector.js`; runtime environment is `.secrets/<INSTANCE>/backend.env`. Keep credentials private. An initialized instance has recovery credentials in its private init.json; manual administrative work is explicit, while automation uses scoped identities.

## Exercise

Deliver the existing AppRole ID/secret ID to the private Agent directory and adapt `vault-agent/config/agent.hcl`. Start only the instance Agent service with the rendered-credential volume shared read-only by the backend. Implement file-based getCredentials and replacement notifications, returning source `vault-agent-dynamic`. The application must work with an empty VAULT_TOKEN; it must never use the Agent sink token or call Vault to fetch its own DB credentials.

After editing connector code, restart the instance backend using Compose. After editing backend.env, recreate it so the environment is reloaded. With default instance and Podman:

```sh
podman compose --env-file config/defaults.env --env-file .env -f .secrets/workshop/compose.yml -p zt-workshop up -d --no-deps --force-recreate backend
make verify LAB=07 RUNTIME=podman
```

Use `docker-compose` in place of `podman compose` for standalone Docker Compose. Adapt paths/project when using another INSTANCE. The verifier checks behavior; it never applies the solution. Probes may create temporary login/lease records and, for CIBA, one uniquely named test order that is deleted afterward.

## Hints

Inspect `data/connector.lab-agent-dynamic.js`, the manifest's required features and existing subsystem docs. Use API/SQL observations to diagnose failures rather than changing completion markers. Preserve getCredentials and the optional lifecycle exports consumed by the existing pool manager.

## Reference solution

To intentionally replace your work, use `make resolve LAB=07 RUNTIME=podman OVERWRITE=1`. Edited connector files are backed up privately. Inspect `ansible/tasks/`, `ansible/library/`, `terraform/workshop/` and the local connector example to understand each change. Manually created mounts/policies require explicit `make adopt LAB=07` before later automated resolution; verification itself never requires adoption.
