# Lab 08: jwt-rotation

Exchange a backend identity JWT with Vault.

## Starting point

Run `make prepare LAB=08 RUNTIME=podman` (or Docker). Use the same INSTANCE and PORT_BASE in every command. Preparation leaves lab 07 completed and this exercise unsolved.

Read [the command and custody guide](../docs/automation/usage.md). Learner code is `.build/<INSTANCE>/backend/connector.js`; runtime environment is `.secrets/<INSTANCE>/backend.env`. Keep credentials private. An initialized instance has recovery credentials in its private init.json; manual administrative work is explicit, while automation uses scoped identities.

## Exercise

Enable JWT auth at `jwt`. Bind JWKS and issuer to the internal Keycloak realm, and create `zero-trust-jwt-lab` with audience `account`, user_claim `email`, and the application database credential policy. In private backend.env set KEYCLOAK_USERNAME=repping and KEYCLOAK_PASSWORD to that LDAP user's workshop password; the client secret was delivered during identity setup. Exchange that backend identity's JWT for a Vault token and use it for dynamic credentials with proactive reissuance. Return source `vault-jwt-dynamic`. Explain why this is a backend identity rather than each caller's Vault identity.

After editing connector code, restart the instance backend using Compose. After editing backend.env, recreate it so the environment is reloaded. With default instance and Podman:

```sh
podman compose --env-file config/defaults.env --env-file .env -f .secrets/workshop/compose.yml -p zt-workshop up -d --no-deps --force-recreate backend
make verify LAB=08 RUNTIME=podman
```

Use `docker-compose` in place of `podman compose` for standalone Docker Compose. Adapt paths/project when using another INSTANCE. The verifier checks behavior; it never applies the solution. Probes may create temporary login/lease records and, for CIBA, one uniquely named test order that is deleted afterward.

## Hints

## Reference solution

To intentionally replace your work, use `make resolve LAB=08 RUNTIME=podman OVERWRITE=1`. Edited connector files are backed up privately. Inspect `ansible/tasks/`, `ansible/library/`, `terraform/workshop/` and the local connector example to understand each change. Manually created mounts/policies require explicit `make adopt LAB=08` before later automated resolution; verification itself never requires adoption.
